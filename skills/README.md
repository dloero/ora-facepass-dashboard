# Skills

Two skills that make written copy sound like a person wrote it.

- `humanize-copy/` is the edit pass. Run it on any draft before it goes out.
- `my-voice/` is the drafting voice. Run Setup once with real samples, then every draft starts in your voice.

Use them together. Draft with my-voice, finish with humanize-copy.

## Install

Claude Code: copy each folder into `~/.claude/skills/` (all projects) or `.claude/skills/` (one project). Then type `/humanize-copy` or `/my-voice`.

Claude.ai or Claude Desktop: zip a folder and upload it as a skill in settings. Or paste the SKILL.md into a Project's instructions.

Any other model (ChatGPT, Gemini, Cursor): paste the SKILL.md as the system prompt or custom instructions. It is plain markdown.
